Polymorphism

-> Polymorphism means "many forms". 
-> There are 2 types of polymorphism:
1) Method Overloading/Compile-Time Polymorphysm/Static Type Polymorphysm/Early Binding Polymorphysm
-> Method Overloading is a type of Polymorphysm where the name of the method is same, but change in datatype or arguement of the methods.
-> Method Overloading is achieved in same class.
RULES OF METHOD OVERLOADING:
1) No Of Arguements Passed
2) Datatype of the Arguement
3) Sequence in which they are passed

2) Method Overriding/Run-Time Polymorphysm/Dynamic Type Polymorphysm/Late Binding Polymorphysm
-> Method Overriding is a type of Polymorphysm where the name of method is same, with the same datatype, arguement and return type in base class as well as dervied class
-> Method Overriding is achieved with the help of inheritance.
RULES OF METHOD OVERRIDING:
1) No of Arguements should be same in base class as well as Derived Class
2) Datatype and Sequence should be same in base class as well as derived class
3) return type should be same in base class as well as dervied class.

Exception Handling

What is Exception?
-> An error occured during the execution of the program is called as runtime error or exception.
-> There are two types of Exception : 
1) Checked Exception:
Any exception which is occured due to system configuration are called as Checked Exception.
Eg : FileNotFoundException is an checked exception.
2) Unchecked Exception:
Any exception which is occured due to programmer's mistake is called as Unchecked Exception.
Eg : ArrayIndexOutOfBoundsException is an Unchecked Exception.

What is Exception Handling?
-> Exception Handling is a technique to handle the runtime error and give appropriate message to users.
-> In Java, to handle runtime error or exception, we use try,catch block.
-> TRY BLOCK :
- Try Block contains the code which may have exception.
- Try block executes the code assuming that there is no exception in the code.
- If any exception occured, it sends it to catch block.
-> CATCH BLOCK :
- Catch block is used to handle the exception in the "try" block.
- Catch block has a parameter of exception type class.
-> FINALLY BLOCK
- Finally block is execute after try or catch block.
- It is used to deallocate the memory allocated in try block
- Finally block will always execute.

What is File?
-> File is a collection of data, stored in secondary storage devices like floppy disk, hard disk, etc.

What is File Handling?
-> File Handling is a technique to read or write a data in a file.

Why File Handling?
- We store data in variable.
- storing data in variable will remain till the execution of the program
- Once program is terminated, data from the variable is lost.
- So if we need to store some data even after the termination of the program, we use file handling.

In order to achieve file handling, there are 3 steps : 
1) Opening a File
2) Reading a File
	OR
2) Writing a File
3) Closing a File

In java, we can read or write files in different ways:
1) Character Based
-> FileWriter & FileReader

2) Byte Based
-> FileOutputStream & FileInputStream

3) Data Based
-> DataOutputStream & DataInputStream
